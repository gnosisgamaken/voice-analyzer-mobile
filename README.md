# Voice Analyzer Workspace

```
voice-analyzer-mobile/
├── app/               # React Native CLI project (current iOS/Android app)
├── docs/              # Planning documents (implementation plans, specs)
└── legacy-expo/       # Archived Expo-managed project and scripts
```

Run all development commands from `app/`. The `legacy-expo` folder is kept only as a reference/migration archive; ignore it unless you need to revisit the old Expo build.
